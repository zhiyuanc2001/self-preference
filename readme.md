
## Response Generation
Generate model responses for AlpacaEval(helpfulness) by `gen_answering.py`

Generate model responses for AlpacaEval(truthfulness) by `gen_truthfulness.py`  

Generate model responses for WMT by `gen_translation.py`  


## Preference Generation
Generate model preference by `gen_preference.py`


##
You can refer to bash fils under `scripts/` for more details to run `gen_*.py`.

We have uploaded the judge model preference results on AlpacaEval (helpfulness), which is in `preferences_helpfulness.tar.gz`.  
Please use `tar -zxvf preferences_helpfulness.tar.gz` to unzip it.


We can't upload all the data due to github storage limitations, and we try to avoid giving links to prevent violating anonymity requirements. We will open source all data when past anonymity.
